# Indefessus brand assets

The one copy of the Indefessus logo and symbol. Use these files as they are: do not redraw, recolour or re-set the lettering. The HTML report reads its logo from this folder when the program is built.

## Which file to use

| Use | File |
| --- | --- |
| Logo on light backgrounds (primary) | `logo-horizontal-ink.svg` |
| Logo on dark backgrounds | `logo-horizontal-paper.svg` |
| Logo that takes the surrounding text colour (web pages, docs) | `logo-horizontal-current.svg` |
| Logo where the symbol is under 48 px tall (headers, footers, the HTML report) | `logo-horizontal-small-ink.svg`, `-paper.svg`, `-current.svg` |
| Symbol alone, 48 px and up | `symbol-ink.svg`, `symbol-paper.svg`, `symbol-black.svg`, `symbol-white.svg`, `symbol-current.svg` |
| Symbol alone, 24 to 40 px | `symbol-small-*.svg` (same colour set) |
| Browser tab icon, 16 to 20 px | `favicon.svg` (switches with light and dark mode), `favicon.ico` and `favicon-opaque.svg` (work on any tab colour) |

Never scale the master symbol below 48 px or the small symbol below 24 px: use the next cut down.

## Colours

Monochrome first. Ink `#121313` on Paper `#F3F2EE`, Paper on Ink for dark backgrounds. Graphite `#5E6163` for secondary text. Oxide `#A8361F` (`#E2734F` on dark) is not a brand colour: in reports it marks only results where the assistant obeyed a stranger.
